# Engineering Onboarding Guide

## Week 1

- Complete IT setup: laptop provisioning, VPN access (see `vpn_setup.md`),
  and SSO enrollment.
- Get added to the `#eng-general` and `#eng-oncall` internal channels.
- Meet with your onboarding buddy (assigned by your manager).
- Read the deployment procedures document (`deployment.md`).

## Week 2

- Set up your local development environment following the repository
  README.
- Complete the "shadow an on-call shift" pairing session.
- Request access to the internal API documentation portal.

## Accounts You Will Need

| System              | Requested By           | Turnaround |
| ------------------- | ----------------------- | ---------- |
| Source control       | Automatic on day 1       | Instant    |
| VPN                  | Support ticket           | 1 business day |
| Internal API docs    | Manager approval          | 2 business days |
| Production access    | Security team approval    | 5 business days |

## Code of Conduct

All engineers are expected to follow the internal engineering handbook.
Production and privileged-tool access follows least-privilege: request
only what your current task requires.

## Who to Contact

- General onboarding questions: your onboarding buddy
- Access/permission issues: IT Operations (open a support ticket)
- Security questions: the security team via `#security`
